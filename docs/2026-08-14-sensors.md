# 2026-08-14 相机 / 雷达实测

授权启动驱动后的记录。活页：[onboard-truth.md](./onboard-truth.md)

## 物理连接（不是「挂载盘」）

### RealSense D435

- USB3 SuperSpeed（sysfs `speed=5000`），口 `usb2-1.1.2`，vid:pid `8086:0b07`。
- Linux **没有把它 mount 成文件系统**。内核驱动 `uvcvideo` 给出字符设备：
  - `/dev/video0`、`/dev/video1`（接口 00）
  - `/dev/video2`（接口 03）
- ROS 驱动不读这些节点当普通摄像头，而是 **librealsense** 走 USB 访问同一设备。

### RoboSense Helios 16

- 网线接 Jetson 板载 `eth0`，协商 **1000 Mb/s Full**。
- Linux **没有块设备、不挂载**。就是一张普通以太网卡上的 UDP。
- 雷达 `192.168.1.200`（MAC `40:2c:76:8a:ce:25`）持续 ARP：谁是 `192.168.1.102`。
- 主机加上 `192.168.1.102/24` 之后 ICMP 通（0.4–8.6 ms），MSOP/DIFOP 才开始进本机。

## 驱动源码与启动

| | 相机 | 雷达 |
| --- | --- | --- |
| 车上源码 | `~/catkin_ws/src/realsense/realsense-ros/realsense2_camera` | `~/catkin_ws/src/rslidar_sdk` |
| 版本 | 2.2.22 | 1.3.2 |

| 话题 | Hz | std(Δt) | 内容 |

## 负担

| 项 | 双开时 |
| --- | --- |
| RealSense nodelet CPU | ~20% |
| rslidar_sdk_node CPU | ~15% |
| GPU | 0% |
| 内存增量 | 可忽略（整机仍 ~2.5 / 31 G） |
| eth0 | 入站 0.9 MiB/s，轻 |
| lo（有人订点云+图） | ~20 MiB/s，这才是本机压力点 |

结论：Xavier 上默认分辨率双开 **压得住**；压力在 CPU 和本机 ROS 拷贝，不在 GPU、也不在千兆网。
